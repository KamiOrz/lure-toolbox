# Third-party assets

The outlined interface icons (`ic_arrow_back`, `ic_arrow_forward`, `ic_add`, `ic_remove`, `ic_volume_up`, `ic_vibration`, `ic_timer`) come from [Google Material Design Icons](https://github.com/google/material-design-icons), licensed under Apache License 2.0. Copyright Google LLC.

Original source: `android/{category}/{name}/materialiconsoutlined/black/res/drawable/outline_{name}_24.xml` in the upstream repository. The theme tint reference was adapted from AppCompat to the Android framework attribute; icon geometry is unchanged. Compose supplies the interface tint.

The license is included in [material-icons-LICENSE.txt](docs/design/material-icons-LICENSE.txt).

The reference mockup was generated for this project. The timer dial is a native, interactive progress visualization driven by the existing service; it is not a rasterized screen.
